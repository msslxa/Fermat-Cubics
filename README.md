# Fermat-Cubics

The library contains several Magma functions computing the birational parametrizations of the Fermat cubic hypersurfaces (of even dimension), and more generally of cubic hypersurfaces of dimension 2n containing a pair of skew and conjugate n-planes, and their inverses as described in the paper "Rational points on even dimensional Fermat cubics" https://arxiv.org/abs/2406.07223.
